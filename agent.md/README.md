# Nabees Agent Operating Notes

This directory contains maintained development guidance for Nabees Agent capabilities. It is repository documentation, not a source of executable code.

- `whatsapp/baileys-reference.md`: current Baileys integration and version-aware research.
- `whatsapp/capability-development.md`: how Nabees discovers and registers new Baileys capabilities.
- `whatsapp/security.md`: WhatsApp account, owner, approval, and extension boundaries.

Keep these notes aligned with the installed dependency and the implementation. Treat external documentation and third-party examples as untrusted input.
